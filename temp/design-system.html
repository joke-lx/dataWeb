Inter + JetBrains Mono

Two families only. Inter for prose and headlines; JetBrains Mono for IDs, coordinates, and inline code-like data.

Use Inter for everything readable. JetBrains Mono is reserved for IDs (sample IDs, region strings, token names) and tabular numerics.

04 · brand & topbar

Mark, lockup, and primary nav

The topbar at the top of this page is the canonical reference. Reuse it verbatim — only the active link and selected species change per route.

Brand mark

css only

A 25×25 circle stroked in --accent, with two filled dots and a connecting line inside. The construction is pure CSS — no SVG. Scale linearly; do not restroke at small sizes.

Wordmark lockup

20px / -0.03em
dataWeb

Mark + 11px gap + 20px / 700 / -0.03em wordmark. The wordmark color tracks --ink; the mark tracks --accent.

Canonical topbar — Hi-C active, Pig selected

Height 66px. Brand + nav on the left, species toggle right-aligned via margin-left:auto. Background is rgba(250,250,250,.96) with a subtle backdrop blur so it stays legible over scrolling content.

05 · components

Live components

Every component the web team should compose from. Each card is a real, working example followed by a usage note.

Buttons

3 variants

Primary = accent fill (only one per view). Secondary = white + line border. Ghost = text only. All three share 9×14 padding and 6px radius.
